# Valane Statistiques - Ashborn Studio

## Presentation

Valane Statistiques est une application locale qui affiche des statistiques liees a Valane.

## Fonctionnalites

- Interface graphique locale.
- Pages de statistiques integrees.
- Recuperation de donnees depuis `https://api.valane.fr`.
- Installation automatique dans le dossier utilisateur Windows.
- Creation d'un raccourci dans le menu Demarrer.
- Verification de la presence de Python pendant l'installation.
- Installation automatique de Python si necessaire.
- Mise à jour

## Installation simple

1. Lancez `installer.exe`.
2. Cliquez sur `Installer`.
3. L'installateur verifie si l'application est deja installee.
4. Si Python n'est pas installe, l'installateur utilise le fichier d'installation Python fourni avec l'executable.
5. Les fichiers de l'application sont telecharges depuis le depot [GitHub](https://github.com/theemberforge2nd/ValaneStat).
6. Un raccourci `Valane Statistiques` est cree dans le menu Demarrer.

Une fois l'installation terminee, l'application est prete a etre lancee depuis le menu Demarrer.

## Information d'Installation


### 1. Dossier d'installation

Par defaut, l'application est installee dans :

```text
%APPDATA%\AshbornStudio\Valane-Stat
```

Le raccourci du menu Demarrer est cree dans :

```text
%APPDATA%\Microsoft\Windows\Start Menu\Programs\AshbornStudio
```
